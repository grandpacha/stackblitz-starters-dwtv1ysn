## TIPS FOR STYLE NAMING

1. Be Consistent
   - Use the same naming convention across all documents
   - Prefer Title Case (e.g., "Body Text" not "body text")

2. Match Common Names
   - Use standard style names when possible
   - This helps automatic mapping work better

3. Avoid Special Characters
   - Don't use: @, #, $, %, &, *, etc.
   - Spaces and numbers are OK

4. Be Descriptive
   - "Pull Quote" is better than "PQ"
   - "Caption Bold" is better than "CB"

5. Create a Style Guide
   - Document your style names
   - Share with your team
   - Keep it updated

## WORKFLOW RECOMMENDATIONS

Before Importing from Word:
1. Clean up Word document formatting
2. Apply consistent styles in Word
3. Remove manual overrides (use styles instead)
4. Check for style name consistency

After Importing to InDesign:
1. Review style applications
2. Adjust any mis-mapped styles
3. Check pagination and flow
4. Verify colors and fonts
5. Place images manually if needed

## ADVANCED: MODIFYING THE SCRIPT

To add permanent custom mappings to the script:

1. Open WordToInDesignFormatter.jsx
2. Find the 'commonMappings' object (around line 366)
3. Add your mappings in this format:
   'wordstylename': ['indesign style 1', 'indesign style 2'],
4. Save and restart InDesign

Example:
var commonMappings = {
    'heading1': ['heading 1', 'h1', 'title'],
    'mycompanyheader': ['company header', 'brand header'],
    'productname': ['product', 'brand name'],
};
